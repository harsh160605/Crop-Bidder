# Crop Bidder

Crop Bidder is a web application that facilitates bidding on crops between farmers and buyers. It is built using Node.js, Express, and EJS for the frontend, with a MySQL database to manage data.

## Technologies Used
- **Backend:** Node.js, Express.js
- **Database:** MySQL
- **Frontend Template Engine:** EJS
- **Other Utilities:** cors, body-parser, dotenv

## Getting Started

### Prerequisites
- [Node.js](https://nodejs.org/) installed
- [MySQL](https://www.mysql.com/) installed and running

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/harsh160605/Crop-Bidder.git
   cd Crop-Bidder
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Set up environment variables:
   Create a `.env` file in the root directory and add the necessary environment variables (e.g., database credentials and port).

4. Start the server:
   ```bash
   node index.js
   ```
